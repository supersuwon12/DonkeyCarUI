# DonkeyCarUI 🚗💨

DonkeyCarUI는 가상 자율주행 환경인 **DonkeyCar 웹 시뮬레이터(Web Simulator)**를 통해 수집된 주행 데이터를 시각적으로 관리하고, 인공지능 모델 학습 과정을 효율적으로 제어하기 위해 개발된 **C# Windows Forms 기반 종합 데이터 엔지니어링 및 학습 제어 GUI 어플리케이션**입니다.

실제 하드웨어 차량 없이도 웹 시뮬레이터 환경에서 가상 주행을 통해 빌드된 방대한 이미지 데이터와 주행 로그(조향각, 속도)셋을 직관적인 UI로 로딩하며, 데이터 정제(Cleaning), 전처리(Preprocessing), 흐름 분석은 물론 Python 스크립트 실시간 연동을 통한 인공지능 자율주행 가상 모델 트레이닝 환경을 원스톱으로 제공합니다.

---

## 프로그램 진행 과정 및 단계

### 1. 프로그램 진행 단계
* **1단계**: 데이터 필터링 및 편집
* **2단계**: 데이터 학습
* **3단계**: 학습 시작 및 종료
* **4단계**: 학습된 데이터 최종 비교

### 3. 프로그램 진행 과정
* **[데이터 필터링 및 편집]**: DonkeyCarUI 프로그램 실행 ➡️ 주행 데이터 불러오기 ➡️ catalog 및 JSON 파일 일괄 로드 ➡️ 타임라인 트랙바 및 프레임 바로 주행 영상 모니터링 ➡️ 충돌 및 이탈 구간 선택 ➡️ 불필요한 데이터 필터링 ➡️ 데이터 보정(밝기, 흐림, 흑백) ➡️ 데이터 리스트에서 상세 정보 확인
* **[데이터 학습]**: 모델 종류 선택 ➡️ 반복 학습 횟수 설정 ➡️ 모델 이름 및 설명 입력 ➡️ 학습 시작 ➡️ 실시간 모델 점수 및 손실값 모니터링 ➡️ 학습된 모델 리스트에서 관리
* **[학습 시작 및 종료]**: 밝기와 흐림효과, 흑백등을 조정해 좀더 나은 데이터가 나오게 해줍니다.
* **[학습된 데이터 최종 비교]**: 현재 사진들의 영상을 설정해줍니다. 배속과 이동이 가능합니다.

## 🔥 핵심 기능 (Key Features)

### 1. 주행 데이터 관리 & 시각화 (Data Management & Visualization)
* **주행 데이터 불러오기**: 시뮬레이터를 통해 얻은 데이터들(`.catalog` , `.json`)을 완벽히 지원합니다.
* **재생 설정**: 재생(▶), 일시정지(⏸), 프레임 단위 이동 및 최대 3배속(1.0x ~ 3.0x) 배속 탐색이 가능한 데이터 플레이어 기능이 내장되어 있습니다.
* **주행 데이터**: 선택한 프레임의 방향 및 속도 데이터를 프로그레스 바와 수치로 실시간 모니터링합니다.
* **범위 필터링**: 사용자가 지정한 방향과 속도 범위에 따라 데이터를 필터링 할 수 있습니다. 
* **데이터 보정**: 메인 화면에 나타나는 프레임의 밝기, 흑백 반전과 흐림 정도를 프로그레스 바로 조절하여 보정할 수 있습니다.
* **선택 범위 편집**: 시작 지점 선택 버튼이나 끝 지점 선택 버튼을 이용하여 프로그레스 바와 프레임 바에 선택 범위를 지정할 수 있습니다. 또한 삭제도 가능하고 안전하게 `.trash` 폴더로 이동시켜서 복원도 할 수 있습니다.
* **데이터 리스트**: 리스트에서 특정 프레임을 클릭하면 해당 프레임의 조향각, 속도 데이터를 상세히 볼 수 있습니다.

### 2.데이터 학습 (Data Training)
* **모델 종류 선택**: Linear, Behavioral 같이 AI 모델을 선택할 수 있습니다.
* **반복 학습 횟수**: 모델이 데이터를 학습하는 횟수를 설정할 수 있습니다. 많은 반복 학습은 모델의 성능을 향상시킬 수 있습니다.
* **학습 시작/학습 중지**: 학습을 시작하거나 중지할 수 있는 버튼이 있습니다.
* **모델 이름/설명**: AI 모델의 이름과 설명을 입력할 수 있는 필드가 있습니다. 이를 통해 모델을 쉽게 식별하고 관리할 수 있습니다.
* **추가 학습 설정**:학습된 AI모델을 불러와 추가학습을 시킬 수 있습니다.
* **학습 모델 관리**:학습된 AI모델을 리스트로 보여줍니다. 모델을 선택하여 추가학습을 시킬 수 있습니다. 또한, 모델을 삭제할 수 있는 기능도 제공됩니다.
* **실시간 모니터링**:모델 점수와 손실값을 보여줍니다. 학습이 진행되는 동안 모델의 성능을 모니터링할 수 있습니다.

### 3.학습 비교보기 (Training Comparison)
* **학습한 AI 모델 데이터 불러오기**: 학습한 AI 모델의 데이터를 불러와서 비교할 수 있습니다.
* **AI 모델 주행 데이터**: 각 모델의 주행 데이터를 상세히 표시합니다.
* **이미지 보정**: 밝기와 흐림 정도를 조절하여 이미지 보정을 할 수 있습니다. 이를 통해 모델의 주행 데이터를 시각적으로 더 명확하게 비교할 수 있습니다.
* **재생 설정**: 모델 비교 시 주행 데이터를 보다 편리하게 재생할 수 있게 재생, 건너뛰기, 배속 등의 기능이 있습니다.
* **주행 데이터**: 실제 주행 데이터를 상세히 표시합니다.
* **주행 표시**: 화살표로 주행 방향을 표시합니다. AI 모델의 주행데이터와 실제 주행데이터를 시각적으로 비교하여 평가할 수 있습니다.

## 💻 단축키 가이드 (추후 구현)

* **`Space`**: 주행 데이터 재생 / 일시정지
* **`◀ / ▶ (방향키)`**: 이전 프레임 / 다음 프레임 이동
* **`Page Up / Page Down`**: 10 프레임 앞으로 / 뒤로 건너뛰기
* **`Ctrl + Z` / `Ctrl + Y`**: 데이터 편집 작업 실행 취소 (Undo) / 다시 실행 (Redo)
* **`Delete`**: 지정한 선택 범위 데이터 일괄 삭제
